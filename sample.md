# Markdown to HTML Demo

Welcome to the **zero-dependency** Markdown converter!

## Features

- Headings (H1 to H6)
- **Bold**, *italic*, and `inline code`
- Code blocks with syntax wrappers
- Blockquotes and horizontal rules
- Unordered and ordered lists
- Automatic dark / light mode responsive CSS styling

### Code Example

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}
console.log(greet('World'));
```
